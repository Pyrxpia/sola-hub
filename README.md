## 🔥 Flame vs. 🕯️ Ember

- **🔥 Sola Flame (Author Edition):** Pre-configured with all active author workflows, dynamic narrative trackers, and the OOC Collaborator Protocol enabled.
- **🕯️ Sola Ember (Core Foundation):** Pristine baseline with only essential `[Core]` foundation directives active. All optional and tracker modules disabled.
- *Note: Both presets are byte-identical under the hood; they differ only in which module toggles are active by default.*

## 🚀 How to Enable GitHub Pages

1. Go to your repository settings on GitHub (**Settings** → **Pages**).
2. Under **Build and deployment** → **Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**! Your site will be live within 1–2 minutes!
